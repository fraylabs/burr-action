# Warnings-mode summaries

With `fail-on-unresolved: false`, an assembly without unaccepted findings now
describes the unchecked pairs plainly, keeps their reasons, and emits one
warning annotation per incomplete assembly. Assemblies that fail to import or
time out say that the check could not be completed rather than suggesting a
complete zero-overlap result. Annotation text escapes workflow control
characters in model paths.

The default mode's summary and failure behavior are unchanged. JSON status
continues to be `incomplete`; policies, pair verdicts, and all pair records are
unchanged. Large summaries still link to the complete JSON artifact. No engine
version or accepted-fit policy changes are included.

Boat proof runs the real Action scripts and checksum-verified released Burr
0.40.5 against pinned Gasherbrum geometry in both modes and a Micron import
failure in warnings mode. The warnings check must exit 0 with ten listed
unknown pairs and one annotation. Default mode must exit 1 with the existing
INCOMPLETE heading. The import failure must remain explicit.
